# SOLTI (Software Online Ticino)

Siamo un piccolo team ticinese che sviluppa software per il mercato Ticinese.

## Il nostro primo progetto: NOTI

NOTI (Noleggio Oggetti Ticino) è una piattaforma digitale per noleggiare tra privati oggetti poco utilizzati, come i giochi da tavolo. Chi possiede un oggetto può metterlo a disposizione e guadagnarci, chi lo cerca può provarlo senza doverlo comprare.

## Cosa facciamo

- Sviluppiamo applicazioni web e mobile per il noleggio tra privati
- Costruiamo strumenti per la gestione di prenotazioni, pagamenti e messaggi tra utenti
